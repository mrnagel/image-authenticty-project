How We Score

Aggregate Confidence Score

Each model outputs a probability p(fake) between 0 and 1. We average these values across all models, then apply the binary entropy function to measure how decisive the combined prediction is:

confidence = 1 − H(p̄)

where H(p) = −p·log₂(p) − (1−p)·log₂(1−p). The final verdict is the majority prediction among models. Confidence is how far the averaged probability is from 50/50.

----------------------------------------

Note: confidence is non-linear — a model needs to be very close to 0% or 100% to score high certainty. For example, a prediction of 89.5% fake may only yield ~51% confidence because the model still has meaningful uncertainty. Only predictions near the extremes reflect near-certain judgements.
